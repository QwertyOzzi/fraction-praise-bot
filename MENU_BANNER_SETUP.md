# Баннер главного меню Addams Custom

## Установка

У бота есть безопасная загрузка баннера из Telegram. Сохранение изображения
не требует выкладывать файл в публичный GitHub и не зависит от диска Render.

1. В личном чате с ботом **технический владелец** отправляет `/setbanner`.
2. По просьбе бота отправляет изображение как **фото**, не как документ.
   Рекомендуется формат **16:9**, минимум 640 пикселей по ширине.
3. Бот подтверждает сохранение фото в Firebase `config/bot_state`.
4. Откройте `/start` или `/menu` — картинка появится **над личным кабинетом**
   с прежними inline-кнопками и ссылкой LEA.

Баннер отображается только в главном меню зарегистрированного агента.
Регистрация, подача отчёта, запрос баллов и панели руководства не изменены.
Сохранённый `menu_banner_file_id` переживает перезапуски и деплои Render.

## Управление

- `/setbanner` — заменить существующую картинку на новую;
- `/removebanner` — убрать картинку, оставить старое текстовое меню;
- `/cancel` — отменить текущий шаг загрузки.

Все команды управления баннером доступны **только техническому владельцу**
по проверенному Telegram ID в личном чате. Обычные агенты, лидеры и
заместители не могут менять баннер. Ключ Firebase в GitHub не публикуется.

Если Telegram откажет в доставке картинки или ID устареет, бот покажет
обычную текстовую карточку с теми же кнопками. Если сохранение в Firebase
не удалось, прежняя версия баннера останется на месте.

Используйте исходное изображение «Addams Custom», приложенное в беседе
с ChatGPT, или его оптимизированный JPEG-вариант. **В GitHub не нужно
ничего загружать вручную.**
